# 着手详情与报告回放（0.16）

本轮继续对照用户提供的 Chessis 20.9 APK，调整选中某一步后的布局与操作。没有在可运行的原版上逐屏验收，以下依据静态资源及控制代码。

## 原版依据

- `.work/chessis-reference/res/layout/dialog_game_report.xml`：选中着手卡片最小高度 82、左侧分类色条、28 图标、15 单行标题、前后局势及 11 号评分、两条 8×30 评分示意、可选变化原因、右侧关闭和前进指示。图表紧接在卡片下方。
- `p328r2/C4566d.m9413j0`：起始局面不创建着手卡片；选中手同时更新图表。分类符号由 `m9412i0` 提供。
- `ViewOnClickListenerC4568f`：整卡点击关闭报告并定位选中手；关闭按钮只清除卡片与曲线选中状态。
- `a2/p.t`、`a2/p.r`：均势／优势／胜势标签及可选局势转变说明。将棋评分先按项目已有尺度换算后判断；卡片数值保持引擎原始单位，以先手为正。`|cp| <= 100` 为均势，`|cp| >= 300` 为胜势。

## 操作

点击曲线、着手列表或关键时刻会显示紧凑卡片。整张卡片进入该手之后的棋盘；右上角关闭只取消选中。详细报告双方统计栏使用实际棋手名称，长名称省略并提供提示。

从报告进入棋盘后，候选线路取自该手之后的保存结果，跳步时同步更新，不重新启动引擎。回放途中连续点击时保留最近一次目标。报告候选数量与实时分析设置相互独立；切回当前对局会清理保存的线路和箭头。主动启用实时分析后重新搜索。

棋盘的“本手解析”提供分类说明与可选战术复核数据，并展示**行棋前**保存的候选线路，以便比较实际着手和更好的选择。预览结束后返回相同的详情页；直接从棋盘预览则返回同一个棋盘位置。“从这里下”保留原报告，将指定位置之前的着手建立为新的可下棋局。

## 动画停顿修复

原 USI 解析为验证线路中每一手，都会调用 `position.legal_moves()` 枚举全盘所有走法。三条线路在一次真实界面刷新中占用约 160–220 毫秒，阻塞首批动画帧。

新增 `ShogiRules.is_legal_move()` 只验证给定着手的移动、障碍、行棋方、升变范围、强制升变、持驹、二步、死格、王安全及打步诘。`legal_moves()` 本身保持原算法，作为差分对照。没有跳过线路合法性检查。

`usi_move16_test.gd` 在完整历史对局的多个阶段及专门的先后手禁手局面中，穷举所有格式正确的 USI 走法，逐项比较单手解析与原全盘生成器。性能记录使用本轮真实引擎三条线路，同时保存两种解析方式的完整着手文字；这是本机格式化耗时，不是 Android 帧率指标。
