# Chessis 20.9 → 将棋：实现对照

本文件记录对用户提供的 `base.apk.1` 的静态检查和截至本项目 0.22.0 的改造。**当前版本不是“所有功能、所有 UI 已完全复制”的完成声明。** 0.9 的动画／赛事库、0.10 的报告设置、0.11 的对弈辅助／教程、0.12 的准确率／阶段报告、0.13 的失误练习、0.14 的着手分类、0.15 的报告摘要、0.16 的着手详情、0.17 的准确率详情、0.18 的紧凑阶段弹窗、0.19 的阶段走势摘要证据分别位于 `review/app/chessis09/` 至 `review/app/chessis19/` 的 `REPORT.md`。0.20 的棋盘、免费功能与赛事更新见 `docs/TESTING-0.20.md`；0.21 的阶段条重排见 `docs/REPORT-PHASE-RIBBON.md`；0.22 的评分图标记和定位见 `docs/REPORT-CHART.md`。

## 参考证据

- 包名：`com.chessimprovement.chessis`；版本：20.9；versionCode：209。
- 解码证据在 `.work/chessis-reference/`：`identity.json`、`res/layout/`、`res/menu/menu_drawer.xml`、`res/xml/preference_main_settings.xml`。
- 主界面依据 `activity_main.xml`，底部控件依据 `bottom_navigation_menu.xml`，侧栏依据 `menu_drawer.xml`，更多操作依据 `dialog_more_options.xml`。
- 主界面原资源包含着手列表、棋盘两侧玩家信息、评分条、候选线路、快速/深度报告和底部导航；页面使用深木色背景、蓝色强调色。将棋版重新实现布局和控件，加入 9×9 棋盘与持驹区。
- APK manifest 要求 `base__abi,base__density` 分包，`com.android.vending.splits.required=true`；`splits0.xml` 另声明 scanner 模块和语言分包。所提供文件本身不含原生 `lib/`。本机 ADB 列表为空，没有运行原版进行逐屏对照；静态布局不能证明实际显示状态、联网内容、所有交互或视觉完全一致。
- 0.10 使用 JADX 1.5.6 补充控制代码证据：`p333s2/C4593a.java` 的默认报告模式、时间、深度；`C4596d.java` 的编辑范围、候选线路数和智能分析标签；`p328r2/C4566d.java` 的全屏报告窗口。3,014 个反编译任务完成，37 处反编译错误，不能当作完整无误源码。
- 未修改用户的原 APK。0.9 将它的 20 个 UI 矢量图标转换为 SVG，并使用深木纹位图；原始路径与哈希保存在 `godot/assets/reference-ui/provenance.json`。没有打包原应用可执行文件、角色插画或国际象棋棋子。

## 已实现的对应功能

| 原版功能 / 页面 | 将棋版实现与边界 |
|---|---|
| 棋盘为主的界面 | 启动直接进入棋盘；深木色页面、蓝色强调色、着手条、玩家信息、分析区和八个底部操作，包含直接悔棋。支持竖屏和横屏。未逐像素核验。 |
| 侧栏 | 棋盘、开始对弈、分析棋谱、局面编辑、棋谱库、开局与练习、设置、备份、关于。 |
| 更多选项 | 悔棋、开局、从当前位置继续、整局分析、注释、棋谱信息、画箭头、保存、导出、认输；增加将棋入玉宣言。 |
| 人机 / 双人 / 引擎互战 | 六档 YaneuraOu 与基础 AI、先后手、用时；电脑对电脑模式。六个将棋练习搭档对应真实六档预算，没有伪造 Elo。 |
| 实时分析 | 原资源对应的独立候选行：评分、横向滚动、播放、箭头开关，支持 1–5 条。预览后返回原局；保留当前棋局和回放位置。 |
| 快速 / 深度报告 | 独立时间/深度模式，默认快速深度 14、深度每局面 1.2 秒；可选 0.1–10 秒、1–30 层。深度报告独立 1–5 候选线路，继承线程/Hash；智能分析使用将棋局面复杂度分配预算。进度、停止、续跑、双方筛选、前后失误留在棋盘下方。详细报告全屏木纹、关键时刻、评分曲线、点击选手详情、候选预览返回、分类饼图/筛选与折叠逐手列表。 |
| 选中着手与报告回放 | 0.16 使用紧凑着手卡片，整卡定位棋盘、关闭只取消选中；棋盘保存线路随当前手更新。本手解析提供行棋前候选、预览返回及直接续下。单手 USI 校验减轻线路格式化造成的动画停顿，保留禁手规则，见 `docs/REPORT-MOVE.md`。 |
| 报告摘要与关键时刻 | 0.15 加入走势摘要、默认一条／最多十条卡片、真实前后评分和原因、点击定位及说明弹窗。0.19 补齐无关键时刻时的阶段表现、持续优势和稳定获胜分支，并调整卡片先后手标记、说明缩进与展开按钮。候选和新摘要条件核对原始 DEX；复杂故事组合及补充转折仍有缺口，见 `docs/REPORT-STORY.md`。 |
| 复习失误 | 0.13 在共用棋盘上出题和判答；按双方／先手／后手、漏着／错失胜机／失误／不精确／锐利／妙手筛选，默认跳过已尝试着手。两级提示、揭晓答案、逐手动画回放最佳线路、重试与下一题、独立答对／辅助／揭晓／跳过统计。退出恢复原局与报告选中手，练习记录进入学习备份。当前仅练习当前报告、仅接受报告首选；尚无跨棋谱题库。 |
| 着手分类 | 0.14 提供十类统计及十一枚原版彩色图标。普通阈值按原 DEX 分支迁移评分尺度，牺牲／多子攻击候选经同深度双候选真实搜索复核；计数筛选、分类说明、失误跳转与练习同步接入。当前战术识别为可核验子集，未覆盖全部复杂条件，见 `docs/MOVE-CLASSIFICATION.md`。 |
| 准确率详情 | 0.17 加入独立木纹弹窗、整局基准线、横向逐手表现图、选中卡片与棋盘定位。保留原将棋手数，排除定式／唯一合法着，支持无评分空态；阶段统计及 ACPL 保持独立入口。见 `docs/ACCURACY-INSIGHT.md`。 |
| 准确率与阶段统计 | 0.12 按参考聚合式迁移将棋评分尺度，增加双方准确率、阶段评分条、ACPL 与 JSON 导出。0.18 将弹窗还原为本方手数、评分胶囊和非零错误图标的紧凑只读卡片；定位由报告图表与着手卡片完成。0.21 主报告按参考重排独立棋手行、胜者奖杯、比例条、可换行指标及百分比格式，新增不可用等级分说明。阶段按将棋交战和王周围攻势估计，尚无棋手等级分校准。见 `docs/PHASE-ACCURACY.md`、`docs/REPORT-PHASE-RIBBON.md`。 |
| 棋谱库 | 搜索、导入、查看、改名、删除、导出、恢复进行中对局；沿用原有原子保存与备份。 |
| 历史大赛对局 | 195 局官方公开完整棋谱，2016–2022 年五大棋战，23,115 手全部回放验证。离线搜索、赛事/年份筛选、分页、原站来源、回放和分析。 |
| 三维落子 | 首帧同步安装起点，途中刷新保留节点，阴影同帧更新；使用实际持驹栏端点；拖动释放直接落稳。2,180 项时序和姿态检查通过。 |
| PGN / FEN | 转为将棋 JSON、USI、SFEN、CSA 与带起点坐标的 KIF。导入先回放合法着手。JSON 完整保存注释和绘图。KIF/CSA 保存文字注释。 |
| 编辑棋盘 | 独立 9×9 编辑盘、双方棋子、升变笔、清空/重置、持驹计数、行棋方、SFEN 读取和应用。校验王玉、总数、二步、死子与非行棋方被将军。 |
| 注释 / 信息 | 每手文字注释与先手、后手、棋战、日期、场所；可随棋谱保存和导出。 |
| 绘图工具 | 触屏/鼠标拖动箭头，点击圆圈，同一标记再次点击可删除，按当前手数保存，支持全部清除。 |
| 回放 | 上一步、下一步、着手条直接跳转、自动播放、速度设置、棋盘翻转；从任意位置建立新的主线棋局。 |
| 开局浏览 | 九条经合法性检查的将棋基本开局与围玉示例，支持搜索与逐手回放。原有两本教材的互动教程继续提供。 |
| 外观设置 | 六种棋盘颜色（含自定义）、二维/平面/三维、两种棋字、明暗、坐标、上步标记、动画速度、受攻击棋子提示。 |
| 对弈 / 声音设置 | 落子确认、合法着手提示、拖动开关、自动转向、电脑落子节奏、玩家名称、音量与试听。 |
| 引擎设置 | 线程、Hash、候选着手数量；应用后重启引擎。 |
| 备份 | 当前棋局、棋谱库、设置、学习进度导出为 JSON；从文件或剪贴板恢复，棋局作为新棋谱导入，可选择恢复设置和学习进度。恢复前保留快照，损坏棋谱在写入前拒绝。 |
| 网络 / 蓝牙 | 保留原有 IP/端口直连与 Android 蓝牙能力。没有把直连描述为互联网匹配服务。 |
| 终局 | 将棋将死、无合法着手、千日手、连续王手千日手、认输、超时、27 点入玉宣言；结果页进入回放、分析与新对局。 |

## 尚未复制或并非一一对应

| 原版项目 | 当前差距 |
|---|---|
| 完整原版 UI | 尚未在可运行的 Chessis 20.9 环境下逐屏观察，原版首次引导、所有弹窗、动画、手势和系统选择器没有逐项像素对照；将棋持驹区也需要额外空间。 |
| 原版扫描模块 | 未实现拍照/图片识别将棋棋盘。原 APK 引用独立 scanner 分包；本地没有其实现或用于将棋的识别模型。 |
| 在线大师棋谱、Lichess 导入与在线内容 | 已有 195 局历史离线库；0.20 加入 26 局近期赛事目录、官方 KIF 下载、缓存与每日目录更新工作流。尚无账号连接或将国际象棋服务转换为将棋服务；GitHub 工作流在发布后启用。 |
| Chessnut 电子棋盘 | 未实现将棋硬件协议与设备连接。保留的蓝牙是手机间对弈，不能当作电子棋盘支持。 |
| 账号、反馈后台、订阅、购买 | 按用户要求，0.20 已删除会员页面、权益检查、购买／恢复接口和配置，全部功能免费开放。账号和反馈后台尚未实现。 |
| 全量机器人、人格和战绩 | 原版多角色库未逐个迁移；当前六档将棋电脑，不具有原版各角色开局偏好、聊天与战绩系统。 |
| 全量开局、陷阱、大师库 | 九条入门示例不等同于原版数据库；完整将棋开局与陷阱题库仍待制作。 |
| 高级分析 | 0.12 已迁移准确率聚合结构与阶段页面，但不是原版国际象棋全部算法的等价实现。0.14 已有十类着手与战术复核，但尚未覆盖原版全部候选识别和复杂子力修正；0.15 已接入主要走势摘要及关键时刻卡片，但原版完整故事分支仍未全部迁移；0.17 已接入逐手准确率图及独立详情，0.18 已调整为紧凑只读阶段弹窗，0.19 已补齐无关键时刻时的阶段表现和稳定获胜摘要；走势摘要中复杂的转折与补充评语、连续王手循环权重、估计 Elo 和其余高级图表尚待实现。0.22 补齐评分图的优势底色、重要着手标记、连线与横纵定位，详见 `docs/REPORT-CHART.md`。数学公式、静态代码证据及将棋适配详见 `docs/REPORT-ANALYSIS.md`。 |
| 变化树 | 可从任意历史局面建立分支棋局；尚无同一棋谱内的任意层级变化树、多分支合并和自动提升变化。 |
| 自动备份 | 当前提供手动完整备份与既有活动存档自动保存；没有周期性全量备份、云备份和系统后台任务。 |
| 所有棋谱方言 | KIF 支持起点坐标格式；非平手 KIF 需要 `#SFEN` 或转换 CSA；未支持全部历史编码、KI2、CSA 的 `AL` 等所有扩展。 |
| 外观完整库 | 当前使用将棋棋字、木制模型和自定义颜色，没有逐个重制原版所有国际象棋棋子包、运动样式编辑器、声音包与强度配色面板。 |
| 全语言 | 既有中日英基础导航仍在；新功能以中文为主，没有复制原版全部语言分包。 |
| 真机与双机 | 本轮没有连接 Android 设备；新 APK 尚未在手机实测，新版蓝牙双机、系统文件选择器和后台恢复仍待验收。历史实测不能代替本轮实测。 |
