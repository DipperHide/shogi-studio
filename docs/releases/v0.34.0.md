# Shogi Studio 0.34.0

持驹区改用浅木色托盘，姓名与计时区分开布局，打开菜单不会压缩棋盘。补充棋盘、设置和保存流程的英文、日文文案并检查窄屏与横屏显示。纯回放不自动归档；修改后可保存、不保存或继续编辑。龙王图标改为浅木色背景，提示继续明确标识升变与不升变。

Wooden hand trays and separate player / clock layouts improve the board. Menus keep the board at its full size. English and Japanese board, settings and save controls were checked in portrait and landscape. Replay does not auto-archive; edited analysis offers Save, Discard and Keep Editing. The Dragon King icon uses a light wood background. Promotion choices remain explicit.
