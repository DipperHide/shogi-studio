# Shogi Studio 0.32.0

提示现在明确区分升变和不升变。候选栏显示完整选择，二维／3D 箭头旁显示对应编号的「成／不成」；同一落点的候选标记分开放置。线路后续着手和失误练习的完整提示也会标出不升变。持驹打入、已升变棋子等不会显示错误标记。

Hints now distinguish **Promote** and **Do not promote** in candidate rows, with matching numbered board badges (**+ / =** in English). Alternatives to the same square stay separate. Continuations and full practice hints also identify declined promotion. Drops and already promoted pieces do not get a promotion badge.

ヒントに成・不成を明記しました。候補欄と盤上の番号付き表示が対応し、同じ移動先の候補も区別できます。読み筋の途中や復習問題の完全なヒントにも不成を表示します。駒打ちや成駒には成りの印を付けません。

- Android ARM64: `Shogi-0.32.0-android-arm64.apk`, versionCode 50, existing development signature.
- Windows x64: `Shogi-0.32.0-windows-x64.zip`.
- Checksums: `SHA256SUMS-0.32.0.txt`.

所有功能继续免费。Android 尚未真机验证；此前 Windows 绘制停顿及筛选关闭偶发失败没有在本次改动中解决。完整原版功能／UI 复刻仍在进行。
