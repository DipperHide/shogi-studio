# Shogi Studio 0.27.0

局面编辑加入独立实时评价、暂停／恢复、拖动摆子、每个载入局面的撤销／重做、已保存局面导航、SFEN 剪贴板和固定底部操作。修复持驹输入框撑宽窄屏页面的问题；取消保留原回放位置，完成正确处理将死局面。编辑器引擎故障最多自动重试两次，关闭或暂停会释放进程。

The position editor adds private live evaluation, pause/resume, piece dragging, per-setup undo/redo, saved setup navigation, SFEN clipboard controls and a fixed footer. Hand inputs now fit narrow screens. Cancel preserves replay context, terminal setups remain finished, and engine failures receive bounded retries with process cleanup.

局面編集に独立した評価値、停止・再開、駒のドラッグ、局面ごとの取り消し・やり直し、保存局面の選択、SFEN 操作と固定フッターを追加しました。持駒入力による画面のはみ出しを修正しました。取消で再生位置を保持し、詰み局面の終了判定、解析エンジンの再試行と終了処理に対応します。

所有功能免费，延续更亮、更宽的 3D 棋盘、固定比例持驹、直接悔棋、龍王图标和官方赛事目录更新。

- Android ARM64：`Shogi-0.27.0-android-arm64.apk`，release 模板、versionCode 45，沿用原开发签名。
- Windows x64：`Shogi-0.27.0-windows-x64.zip`。
- SHA-256：`SHA256SUMS-0.27.0.txt`。

高级界面主要为中文；拍照识别未实现。测试不能保证绝对没有 bug，本版未连接 Android 真机，Windows 测试环境的周期性绘制停顿仍未解决。GitHub 发布和每日赛事工作流尚待本机授权恢复后执行。见 [验证记录](../TESTING-0.27.md) 和 [局面编辑说明](../POSITION-EDITOR.md)。
