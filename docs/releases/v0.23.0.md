# Shogi Studio 0.23.0

中文：报告分类区默认收起次要统计，展开后显示完整十类计数和三色环形图。按原算法计算质量加权占比，点击显示说明，支持旋转与键盘选择。点击分类返回棋盘定位，棋盘分类按钮可连续查看同类着手。

English: Report statistics now expand from the compact category table into all ten counts and two quality doughnuts. Weighted percentages follow the inspected reference algorithm and are explicitly labeled. Touch rotation, keyboard selection, quality explanations and category navigation back to the board are supported.

日本語：分析レポートの分類表を折りたたみ表示に変更し、展開すると全 10 分類と先後の品質ドーナツグラフを表示します。重み付き割合を明記し、タッチ回転、キーボード選択、説明表示、分類から棋譜への移動に対応しました。

所有功能免费，包含此前调亮加宽的 3D 棋盘、带动画的分析回放、续下、近期赛事目录及 195 局离线历史。中英日 README 随源码提供。Android ARM64 APK 为 release 模板、既有开发签名；Windows ZIP 请完整解压。校验文件为 `SHA256SUMS-0.23.0.txt`，测试详情见 `docs/TESTING-0.23.md`。

No physical Android device was connected. Tests reduce regression risk but cannot guarantee zero bugs or complete parity with the reference app. The tournament update workflow requires this repository's default branch to be published and enabled.
