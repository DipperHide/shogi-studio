# Shogi Studio 0.20.0

中文：3D 棋盘更亮、更宽；移除全部会员和付费解锁。加入 26 局近期日本赛事目录、官方棋谱下载与离线缓存，保留 195 局离线历史库；配置每日目录更新。三语 README 已提供。

English: Brighter, wider 3D board. All membership and purchase flows removed. Recent official tournament catalog, validated KIF downloads and offline caching, alongside 195 historical games. Daily catalog update workflow and Chinese/English/Japanese READMEs included.

日本語：3D 盤を明るく幅広く調整。会員・課金機能を削除。最近の公式大会一覧、検証付き KIF 取得、オフライン保存、195 局の過去棋譜を提供します。日次更新ワークフローと中・英・日文 README を同梱しました。

下载 APK 安装 Android ARM64 版；Windows 请下载 ZIP 并完整解压。APK 为 release 构建，沿用原开发签名，支持同签名版本覆盖升级。No physical Android device was connected for this release. Tests cannot guarantee zero bugs.

验证：5,259 项检查通过；独立规则对照 280 局面 / 8,932 着手；近期 26 局 / 3,092 手和历史 195 局 / 23,115 手逐手验证通过。详情见仓库 `docs/TESTING-0.20.md`，校验值见附件 SHA256SUMS。
