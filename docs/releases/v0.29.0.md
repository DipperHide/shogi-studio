# Shogi Studio 0.29.0

开局与围玉现在支持组合筛选、中英日名称搜索，以及独立的动画预览棋盘。先查看、翻转、播放或逐手定位，再将选中位置载入主棋盘；退出保留原棋谱和列表状态。横屏并排显示完整棋盘与操作，竖屏固定载入按钮。

Opening and castle examples now have combined filters, multilingual aliases and a separate animated preview. Inspect, flip, play or select a move before loading it on the main board. Closing preserves the original game and list state; landscape shows the entire board beside its controls.

戦法・囲いの例に絞り込み、多言語の別名検索、独立したアニメーション付きプレビューを追加しました。反転・再生・手順選択後に本盤へ読み込めます。閉じると元の棋譜と一覧の状態を保持し、横画面では盤面と操作を並べます。

- Android ARM64：`Shogi-0.29.0-android-arm64.apk`、versionCode 47，release 模板，沿用开发签名。
- Windows x64：`Shogi-0.29.0-windows-x64.zip`。
- SHA-256：`SHA256SUMS-0.29.0.txt`。

全部功能免费。九条教学示例不是完整定式库，没有大师胜率数据。保留调亮、加宽的 3D 棋盘、龍图标、历史赛事库和每日更新支持。GitHub 登录尚未恢复，仓库、Release 和每日工作流仍未发布／启用；Android 真机验收和 Windows 绘制停顿问题仍待解决。
