# Shogi Studio 0.28.0

棋子移动先显示起点，再按实际绘制帧推进。绘制停顿后继续播放剩余移动，避免落子、吃子、升变、打入和反向回放突然跳到末尾；教程使用相同机制。保留不同动画速度、关闭动画、暂停恢复与中途定位。

Piece animations now show their starting pose before advancing through rendered frames. Delayed frames no longer consume the rest of a move in one jump. Main-board and lesson movement share this behavior, including captures, promotion, drops and reverse replay, with speed controls and continuous retargeting.

駒の開始位置を表示してから移動を進め、描画の遅延で残りの動きが一度に飛ばされることを防ぎます。盤面とレッスンの駒取り、成り、駒打ち、逆再生に適用し、速度設定と移動中の再選択を保持します。

低帧率或停顿时实际播放时间可能延长。Windows 测试机的绘制停顿本身仍未解决；没有 Android 真机数据。所有功能免费，包含调亮、加宽的 3D 棋盘、龍王图标、历史赛事库及每日目录更新功能。
