# Shogi Studio 0.26.0

分析区新增完整评价条，显示刻度、评分和深度。支持底部、左侧、智能布局，以及仅报告回放时移到左侧。评分变化有连续动画；报告回放正确保留实际詰手数和搜索深度，左侧布局也能暂停分析、调整候选线路和直接续下。

The analysis board now has a ticked evaluation bar with score and depth, supporting bottom, left, smart and report-only side placement. Animated score updates preserve their current position. Report replay keeps actual mate distances and search depth; engine controls and continuation remain available beside the board.

解析画面に目盛り・評価値・探索深度付きの評価バーを追加しました。下部・左側・自動配置・棋譜解析の再生時のみ左側を選べます。評価値の変化は滑らかにつながり、詰み手数と探索深度を保持します。左側表示でも解析操作と選択局面からの対局再開ができます。

所有功能免费，延续更亮、更宽的 3D 棋盘、固定比例持驹、直接悔棋、龍王图标与官方赛事目录更新。

- Android ARM64：`Shogi-0.26.0-android-arm64.apk`，release 模板、versionCode 44，沿用原开发签名。
- Windows x64：`Shogi-0.26.0-windows-x64.zip`。
- SHA-256：`SHA256SUMS-0.26.0.txt`。

高级界面主要为中文，完整变化使用 JSON 保存。测试不能保证绝对没有 bug；本版未连接 Android 真机，Windows 测试环境的周期性绘制停顿仍未解决。GitHub 发布和每日赛事工作流尚待本机授权恢复后执行。见 [验证记录](../TESTING-0.26.md) 和 [评价条说明](../EVALUATION-BAR.md)。
