# Shogi Studio 0.37.0 · 中将棋

加入完整 12×12 二维中将棋：同机双人、自由摆局、保存与回放、IP 直连和安卓蓝牙。采用日本中将棋连盟 2019 规则及补充解释，支持狮子、飞鹫、角鹰的多段移动、居食、往返、狮子交换限制、太子与重复责任。多段着手作为一手确认和同步。

手机支持双指缩放至 3 倍、平移、复位、翻转及横向棋路。长按棋子查看走法。中将棋使用独立规则、存档和协议；不提供中将棋电脑对手或引擎分析，进入时停止本将棋分析任务。

本版同时正式收录 0.36 系列改进：可展开分析区、上下和候选线路左右滚动、完整虚拟棋路、持驹拖动修复、自动分阶段分析与缓存、坏棋提示及悔棋重试，以及“随手／启蒙／新手／基础练习”四档弱电脑。分析仅显示玩家侧的候选线路，强分析引擎不会替代弱电脑选棋。整局报告仍手动启动。

两种棋的当前对局分别保存，棋谱库标明棋种。备份升级为版本 2，兼容版本 1；恢复前逐手校验。中将棋仅使用自身 JSON 格式。

Android 包名与签名保持一致，versionCode **58**，可覆盖升级保留数据。Windows 解压后运行 `Shogi.exe`，保留旁边的 `engines` 文件夹。两个平台均免费使用。

手机选子、缩放和平移已获得用户认可；安卓与 Windows 轮换房主通过 IP 对弈、悔棋、断线重连、再战和和棋测试。**尚未完成双手机蓝牙实测**，蓝牙已完成协议与适配器自动化验证。详见 [验证记录](../TESTING-0.37.0.md)。

English: Adds engine-free 2D Chu Shogi with local play, setup, replay, direct IP and Android Bluetooth, plus mobile analysis fixes and four weaker standard-shogi opponents. Analysis never changes the weak opponent’s move selection. Physical Bluetooth testing with two phones has not been completed.

日本語：エンジンを使わない二次元の中将棋、同一端末対局、局面編集、棋譜再生、IP 直接接続、Android Bluetooth を追加しました。本将棋の解析画面と初心者向け4段階も改善。解析が弱い相手の指し手を変更することはありません。スマートフォン2台での Bluetooth 実機試験は未実施です。
