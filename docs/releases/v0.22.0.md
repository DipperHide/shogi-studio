# Shogi Studio 0.22.0

中文：评分图补齐双方优势底色、关键着手图标、连线和横纵定位线。密集图标按行棋方错行，点击图标可选中对应着手；支持键盘和拖动定位。图表边距与阶段标题对齐，新增展开动画，保留回放和续下流程。

English: The score chart now shows separate advantage zones, significant-move icons, connectors and selection crosshairs. Nearby icons stack by player and select their original move. Keyboard and drag navigation, aligned phase boundaries and a reveal animation are included; replay and continuation remain available.

日本語：評価グラフに先後の優勢領域、重要な着手のアイコン、接続線と選択位置の縦横線を追加。近接アイコンは先後別に配置し、対応する指し手を選べます。キーボード・ドラッグ操作、段階境界の位置合わせ、表示アニメーションに対応しました。

全部功能继续免费，包含此前调亮加宽的 3D 棋盘、近期赛事更新目录、195 局离线历史和中英日 README。Android ARM64 APK 使用 release 模板和既有开发签名；Windows ZIP 请完整解压。测试详情见 `docs/TESTING-0.22.md`，文件散列见附件 `SHA256SUMS-0.22.0.txt`。
