# Shogi Studio 0.30.0

分析入口改为内嵌棋谱输入、粘贴／文件卡片、分段来源页签与最近棋谱列表。文件和长文本在独立线程校验，保留完整注释；载入后直接回放、分析或续下。修复最近棋谱空搜索、浅色输入对比度和返回键取消文件选择后的按钮状态。

Analysis import now uses an inline record field, paste/file actions, source tabs and a searchable Recent Games list. A private worker validates the complete record and comments before opening analysis. Fixed empty recent searches, light-theme contrast and retrying file selection after Back.

分析画面に棋譜入力、貼り付け・ファイル操作、入力元タブ、保存済み棋譜の検索一覧を追加しました。全文とコメントを別スレッドで検証してから分析盤へ読み込みます。検索文字なしの一覧、ライトテーマの視認性、ファイル選択を戻った後の再操作を修正しました。

- Android ARM64：`Shogi-0.30.0-android-arm64.apk`、versionCode 48，release 模板，沿用开发签名。
- Windows x64：`Shogi-0.30.0-windows-x64.zip`。
- SHA-256：`SHA256SUMS-0.30.0.txt`。

全部功能免费，保留较亮、较宽的 3D 棋盘、龍图标、195 局历史棋谱与近期官方目录。输入限制 2 MiB；超过 16,000 字只缩短屏幕预览。支持 UTF-8／CP932；不支持将国际象棋 PGN 转为将棋或 Lichess 账号导入。

中英日 README 已更新。Android 真机尚未验收，Windows 绘制停顿本身仍未解决。GitHub 凭据尚未恢复，仓库、Release 和每日更新工作流尚未发布／启用。
