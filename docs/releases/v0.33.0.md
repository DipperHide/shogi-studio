# Shogi Studio 0.33.0

棋谱库新增“我的棋谱 / 大师棋谱”页签、收藏、标签、信息编辑、独立动画预览及局面筛选。预览可保留选中手数载入分析；升变和不升变继续明确标识。收藏与标签纳入备份，旧棋谱仍兼容。

The record library now shares My games / Master games tabs, with favorites, tags, metadata editing, animated previews and position filters. Load a preview at its selected ply. Promotion choices remain explicit. Favorites and tags are included in backups; older records remain compatible.

棋譜一覧に自分の棋譜／大会棋譜のタブ、お気に入り、タグ、情報編集、アニメーション付きプレビュー、局面検索を追加しました。選択手数を保って解析に読み込めます。成・不成を明示し、バックアップにはお気に入りとタグも含めます。旧棋譜にも対応します。

- Android ARM64: `Shogi-0.33.0-android-arm64.apk`, versionCode 51, existing development signature.
- Windows x64: `Shogi-0.33.0-windows-x64.zip`.
- Checksums: `SHA256SUMS-0.33.0.txt`.

所有功能免费。尚未实现棋谱批量操作、跨棋谱练习及已分析筛选。Android 未真机验证；此前 Windows 绘制停顿及大赛筛选关闭的偶发失败仍未确认解决。完整复刻继续进行。
