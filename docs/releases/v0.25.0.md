# Shogi Studio 0.25.0

同一份棋谱现在可以保留多层变化。棋盘上方显示主线与当前分支；长按着手可提升主线、编辑注释或删除后续变化，删除与替换均可撤销。完整树自动归档，也能通过 JSON 导出和备份。从选中的变化局面可以直接继续下棋。

Nested variations now share one analysis record, with a two-row move ribbon, long-press actions, branch comments, undoable deletion/replacement, complete JSON export and backup, and continuation from the selected branch.

一つの棋譜に入れ子の変化を保存できます。二段の指し手欄、長押しメニュー、変化ごとの注釈、削除・置換の取り消し、全変化の JSON 出力・バックアップ、選択した変化からの対局再開に対応します。

所有现有功能免费；延续更亮、更宽的 3D 棋盘、直接悔棋、龍王图标与官方赛事目录更新。

- Android ARM64: `Shogi-0.25.0-android-arm64.apk`，release 模板、versionCode 43；沿用前版开发签名。
- Windows x64: `Shogi-0.25.0-windows-x64.zip`，解压后运行 `Shogi.exe`。
- SHA-256: `SHA256SUMS-0.25.0.txt`。

完整变化使用 JSON；KIF／CSA／USI 仍只导出主线。高级页面主要为中文。Windows 测试机上的周期性绘制停顿仍未完全解决；本版未在 Android 真机测试。赛事每日更新工作流需在默认分支启用。见 [验证记录](../TESTING-0.25.md) 与 [变化使用说明](../VARIATIONS.md)。
