# Shogi Studio 0.24.0

中文：快速切换分析回放时，从棋子当前显示的位置继续移动。吃子、打入、反向回放和升变翻面不会重置到上一动画的目标位置。增加两种棋盘、两个方向、连续跳转的姿态回归和帧时间诊断。

English: Replay now retargets immediately from the currently displayed piece poses. Captures, drops, reverse replay and promotion flips preserve their position, scale and orientation when interrupted. Deterministic regression tests cover both board styles and orientations; actual frame timings are recorded separately.

日本語：解析中の再生位置を変更すると、表示中の駒の姿勢から移動を継続します。駒取り、駒打ち、逆再生、成りの裏返しが途中で元の位置に戻る問題を修正しました。2D／3D と先後反転の連続操作テストを追加しました。

所有功能免费，包含调亮加宽的木制棋盘、主界面悔棋、续下、好棋线路、胜率估计、近期赛事及 195 局离线历史。中英日 README 随源码提供。Android ARM64 APK 使用 release 模板和既有开发签名，versionCode 42；Windows ZIP 请完整解压。校验文件：`SHA256SUMS-0.24.0.txt`。详情：`docs/TESTING-0.24.md`。

Known limitation / 已知限制 / 既知の制限：本机 Windows 空窗口仍有约 450 毫秒的周期性绘制停顿，尚未解决。An intermittent rendering stall remains on the Windows test machine, including in an empty window. Windows 検証機では空のウィンドウでも描画停止が残っています。Android 未连接真机；测试不保证零 bug 或完整复刻。赛事定时更新需仓库默认分支发布并启用工作流。
