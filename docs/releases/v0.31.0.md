# Shogi Studio 0.31.0

历史大赛改为完整木纹列表和底部筛选面板：赛事多选、年份与关键词组合、应用／取消／重置、分别保留近期和离线的列表状态。整行点击载入，显示单局下载进度与缓存标记。完整棋谱在独立线程校验，过期请求不会覆盖新的页面或棋局。

Tournament games now have a full wooden list and bottom filter sheet, with multiple events, year/keyword filters and separate recent/offline list state. Tap a row to load it; per-game progress and cache marks show its actual state. A private worker validates full games, and stale results cannot replace the current replay.

大会棋譜を木目の一覧と下部フィルターに変更しました。大会の複数選択、年・キーワード、適用・取消・リセット、一覧位置の保持に対応します。行全体から読み込み、対局ごとの進捗と保存状態を表示します。全手の合法性を別スレッドで確認し、古い結果による棋譜の置き換えを防ぎます。
