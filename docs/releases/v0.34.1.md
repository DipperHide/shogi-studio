# Shogi Studio 0.34.1

修正日文模式下菜单、教程混用不同粗细字体的问题：正文及标题的备用字体分别匹配常规和标题字重，切换语言时已有标题同步更新。补齐菜单“局面编辑”和“关于”的日文、英文文案。

“推荐好手／推奨手順”与底部搜索按钮共用开关：首次点击显示推荐线路，再点停止分析并关闭箭头和候选着手。两个入口可交替操作，迟到的引擎结果不会重新显示已关闭的提示；候选预览中再次点击也会返回原局面并关闭。

Japanese menus and lessons now use matching weights for fallback glyphs. Existing headings update when changing language. Best Line and Search share one toggle: tap again to stop analysis and hide hints, including while previewing a candidate line.

日本語表示のメニューと学習画面で、代替フォントの太さを本文・見出しに合わせました。「推奨手順」は検索ボタンと同じ切り替え操作になり、もう一度タップすると解析と候補表示を終了します。

- Android ARM64: `Shogi-0.34.1-android-arm64.apk`, versionCode 53, previous development signature retained.
- Windows x64: `Shogi-0.34.1-windows-x64.zip`.
- SHA-256: `SHA256SUMS-0.34.1.txt`.

本次修复字体显示与提示交互；课程内容仍有未翻译的中文，不代表教程已全部翻译。所有功能免费。
