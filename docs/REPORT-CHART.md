# 评分图的参考与将棋适配

0.22 继续适配用户提供的 Chessis 20.9 评分图。原 APK 依赖未提供的分包；以下依据是布局、控制代码和原始 DEX，不是原版动态截图比较。

## 原始依据

- `res/layout/dialog_game_report.xml`：图表高 168 dp；位于选中着手卡片和阶段报告之间。
- `p328r2/C4570h.java`：评分轴固定为 ±10；左右额外偏移 8 dp，上下 10 dp，最小偏移 6 dp。禁用缩放、坐标标签、边框和图例。上半区底色 `#323A42`，下半区 `#090C10`；两色从零评分分界延伸，由视图边界裁剪。零线和阶段线宽 1.1 dp，阶段线为 3／3 dp 虚线。
- `p328r2/C4566d.java`：线宽 2.2 dp；没有数据点圆圈。只标出妙手、锐利、失误、漏着和错失胜机，图标实际大小 12 dp。选中位置显示蓝色横纵定位线。
- `CustomLineChart.onDraw`：上下分别写双方名称；按实际行棋方将图标排在上下边缘，同方相邻图标间距不足 14 dp 时错行。图标中心和曲线之间绘制细连接线，保留命中位置。
- `CustomLineChart.onTouchEvent`：移动距离小于图标尺寸的轻点优先寻找最近图标，命中半径 12 dp，严格排除等于半径的点。
- `p254h4/RunnableC3483A.java` 的分支 9：图表完成布局后，用实际绘图区左右偏移调整阶段标题与评分组。0.21 只依据静态 XML 的 12 dp；0.22 补上运行时的 8 dp 对齐及标题分隔线。

原始文件保存在本机 `.work/chessis-reference/`。JADX 将图标邻近判断反转；`CustomLineChart.onDraw` 原始 DEX 的 `00ff..0195` 明确在距离小于 14 时增加错行层级，大于或等于时重置。`scripts/verify_chart22_dex.py` 用有限解释器独立执行该范围，不运行任意类或 Android 接口。

## 实现

`shogi_report_chart_model.gd` 保存坐标换算、分类筛选、图标排列和命中算法；`shogi_report_chart.gd` 绘制原版图形要素并连接现有着手选择。图标对应实际报告的原手数、行棋方和分类；只显示已完成分析的样本。零评分位于中线，正分有利先手，负分有利后手。

评分换算沿用项目现有的将棋胜率尺度，将原版 ±1000 cp 范围映射为约 ±2209 将棋引擎单位；没有因为更换绘图方式改变准确率或着手分类。原始数值仍显示在选中着手卡片中。

鼠标／触摸轻点和拖动均能定位；键盘左右选择着手，Home 返回起始局面，End 选择最后已分析着手。打开或操作评分图不会改动正在进行的棋局。图标增加后仍保留原有动画回放、候选线路和从选定局面继续下的行为。

原控制代码配置 `phaseX` 的 800 ms 立方渐进动画，但优化后的动画类 DEX 没有保留相应属性，无法从静态配置证明原版实际动画。本项目实现该配置效果；操作图表时立即显示完整已分析曲线，不延误选择。

## 验证与边界

核心检查覆盖 18 组密集布局、上下镜像、14 dp 分界、12 dp 命中分界、连线和裁剪，1,080 个图标另与原始 DEX 结果比较。真实历史局面经实际引擎重新分析，在四尺寸和明暗模式进行触摸、键盘、拖动、图像像素与成品验证。详见 [0.22 测试记录](TESTING-0.22.md)。

本次没有完成棋手等级分校准、全部战术分类、完整变化树或原版全界面动态对照。Android 新版仍需真机验证。
