## 手机与本将棋回归

手机竖屏逻辑尺寸 360×800，横屏 800×360。实机验证点击落子、横竖屏棋盘与控制区、进入与退出中将棋；程序探针验证多段着手只在确认后提交、取消与前后台通知、缩放平移和引擎隔离。用户实际体验了选子、双指缩放和平移。中将棋画面期间未运行引擎进程。

最终调试包在手机横竖屏各通过 31 项中将棋界面检查。本将棋安卓安装包探针通过 167 项；Windows 发行包探针通过 165 项，包含真实引擎搜索与报告。安卓系统 DocumentsUI 打开／取消／再次打开通过 12 项检查，原输入保持完整。文件解析核心另通过 28 项。新增回归覆盖安卓文件返回到当前中将棋页面，以及损坏 JSON 不覆盖局面。Windows 明暗两种主题均验证了中将棋布局。

本将棋核心回归：难度 370、规则 671、提示 242、历史 213、变化 67、棋谱库 48 项通过。界面回归：分析体验 151、棋盘布局 755、保存续下 121、回放导航 79、变化界面 110、个人棋谱库 169 项通过。覆盖弱电脑选棋与分析隔离、只显示玩家侧线路、持驹拖到工具栏松手、暂停分析、缓存、展开分析与棋路滚动。持驹问题以输入事件重现旧风险路径；未将此等同于穷尽所有实机异常。

打包回归发现并修正了 Godot 4.7 的 JNI 插件探测兼容问题：Java 方法使用 `has_java_method` 查询，不能依赖 `Object.has_method`。这影响安卓系统文件选择、导出和主题跟随。赛事目录测试改为校验完整有效目录，不再将自动更新后的局数固定为 26。

原有分析性能与弱电脑固定种子梯度记录见 [0.36](TESTING-0.36.0.md) 与 [0.36.1](TESTING-0.36.1.md)。本次没有把中将棋无引擎的响应时间当作本将棋引擎加速数据，也未进行双手机蓝牙测试。

## 复现与交付

```powershell
./scripts/test_chu37.ps1
./scripts/test_experience36.ps1 -CoreOnly
./scripts/test_experience36.ps1 -SkipCore
./scripts/test_android_device.ps1 -SkipInstall -ReportDirectory review/app/chu37/android-standard
./scripts/test_package.ps1 -ReportDirectory review/app/chu37/build -Executable builds/windows-0.37.0/Shogi.exe
```

`review/app/chu37` 保存本机日志、JSON 与截图，未将手机私人内容上传。正式包的签名、资源、版本、实际引擎搜索和 SHA-256 验证结果汇总为 Release 随附的 `validation-0.37.0.json`；安装包与 Windows ZIP 使用独立新版本文件名，保留旧发行资产。CI 在发布正式 Release 之前运行。
