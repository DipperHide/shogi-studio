# 着手分类与战术复核（0.14）

报告现提供定式、妙手、锐利、最佳、优秀、好棋、不精确、失误、漏着、错失胜机十类。双方计数可点击筛选，说明页另列唯一合法着；唯一合法着计入最佳，但不计入准确率。棋盘下方的分类栏可横向滚动。失误跳转包含错失胜机，练习筛选新增错失胜机、锐利和妙手。

这是按所给 Chessis 20.9 APK 迁移并适配将棋的分类，不是原版全部复杂战术判定的等价实现。输出模型为 `shogi-classification-14-reference-adapted`，逐手导出保留输入评分、阶段、战术候选依据、复核搜索预算与两条实际候选线路。

## 原 APK 的可核实证据

- `move_classifications_explaination.xml` 有十类分类及唯一合法着的十一枚图标；`dialog_game_report.xml` 的统计表为十行。因此本版单独解释强制着，并将其计入最佳。
- `p232e2/AbstractC3188m.java` 的 `m6707N0` 对应普通评价分类，`m6758a`、`m6763b` 处理詰み变化；`p232e2/C3168b0.java` 的 `m6635a` 包含劣势放宽系数。
- `p301n1/C4353c.java` 的 `m8926i`、`p268j0/C4098b.java` 的 `m8356h` 筛选特殊候选并在原着前局面发起双候选复核；`p054H1/C0465H.java` 的 `m834b` 根据首选身份、候选差距、牺牲标记决定是否保留特殊分类。
- `p164W/C1491g.java` 的 `m2256y`、`m2255x` 和 `AbstractC3188m` 的 `m6839s` 涉及新出现的战术／子力牺牲、此前己方着手、被迫应手和普通回吃等排除条件。复杂分支存在反编译错误，本版只迁移可解释的将棋子集。
- JADX 部分布尔分支被错误反编译。本轮用 `scripts/dump_reference_methods.py` 直接读取原始 DEX，核对 `Le2/m;.N0`、`Le2/m;.b`、`LH1/H;.b` 的跳转。原始指令证据在 `.work/chessis-reference/dex-evidence/`，未修改原 APK。
- 十一枚分类 SVG 从 APK 原矢量转换，保留原颜色、透明度、描边和分组变换。`godot/assets/reference-ui/provenance.json` 记录原资源与解码内容散列，发布清单另记转换后文件的散列；目前共 33 枚 UI 矢量加一张木纹。

## 普通分类

先按内置开局共同前缀识别定式；唯一合法着及与引擎首选相同的着手归最佳。其他着手将原生将棋分除以 `2.209248`，使用与准确率一致的评分尺度迁移。阈值结合行棋前后的优势幅度、正负方向、终局状态、评价变化和胜率损失；不再只按固定损失区间分类。

例如，归一化评分从至少 +500 降到 +200 或以下，会区分为错失胜机。其他大优、大劣局面会适当放宽普通损失阈值；仍明显占优时漏掉一步詰み、错过可取子力或送掉子力另作核验。詰み信号使用有符号距离哨兵；长于 49 手的距离当前按 49 处理，不声称完全保留远距离詰み差异。

终局状态在同一报告内只前进，不因某一步王周围攻势减弱又恢复中局阈值。停止／继续保留阶段上下文。

## 妙手与锐利

只有原报告首选着且不是唯一合法着，才可能成为候选。当前检测新出现的非步子力牺牲和同时攻击多个非步目标的战术；比较此前己方着手后的局面，排除把已经悬空的棋子换个位置、原有攻击、普通回吃和常规将军应手等情形。

子力交换使用合法着手，计入被吃子进入对方持驹的价值、升变增益和最多六层回吃。此局部搜索并非完整战术证明，不覆盖全部远距离组合、牵制和反击。

完成常规报告后，候选在原着前局面另作 100 毫秒、MultiPV=2 的真实 YaneuraOu 复核。只接受同一完成深度的两条无上下界评分，首选必须仍是原着；再按原版对应的优势、候选差距和牺牲条件决定妙手／锐利，否则保留最佳。界面显示复核进度，停止后可继续，已完成的局面分析不重复。复核不覆盖原报告的评分或候选线路。

实际验证发现引擎默认 `PvInterval=300` 会让短复核只收到最后的混合深度／界限输出。报告引擎现设为 0，保存每个完成深度并选最高完整双候选，实时分析仍沿用原有刷新间隔。

## 验证与限制

`classification14_test.gd` 检查阈值、詰み、强制着、定式、牺牲、假阳性、目标吃子合法性和复核拒绝条件。`classification14_engine_test.gd` 使用真实银将双攻与送飞车局面，验证锐利、错失胜机和复核暂停／续跑。`chessis14_test.gd` 从本轮引擎结果读取界面数据，覆盖四种尺寸、分类筛选、说明页、好棋练习与原局隔离。`chessis12_test.gd` 重新分析完整历史对局，检查所有特殊分类均有同深度实际复核证据。

仍未迁移原版所有候选识别、复杂子力修正、连续王手循环权重、完整故事摘要和估计 Elo。特殊分类随分析预算和引擎搜索变化；未识别的复杂好棋可能仍显示最佳。原版 APK 缺少运行分包，当前为静态依据对照。新版结果、截图与成品验收见 `review/app/chessis14/REPORT.md`。
