# 0.36.0 本地测试版：分析与新手对弈

本次提供 Android ARM64 和 Windows x64 **本地测试包**，版本名 `0.36.0-test`，Android versionCode 56。没有发布到 GitHub Release，也没有安装到手机。

## 操作变化

- 分析栏可以拖高，也可以点“展开／收起”；返回键先收起。横屏在棋盘右侧展开。纵向滑动查看全部结果，候选线路独立横向滑动，评分与播放按钮保留在两侧。
- 顶部棋路覆盖完整棋谱，主线和变化仍分两行。仅创建可见范围附近的按钮；手动滑动不会被自动拉回。
- 进入分析、导入棋谱和回放自动开始分析；在“引擎与分析”中可关闭。暂停会保持到本次分析会话结束，整局报告仍手动启动。
- 玩家明显失误时显示初步提示，可以查看更好线路、悔棋重试或关闭。电脑已经应手时，重试一并退回该应手。提醒使用报告的评分换算及分类，不将评分上下界当作确定结论。
- 增加“随手、启蒙、新手、基础练习”四档，新安装默认“启蒙”。旧六档和旧棋谱中的难度编号保持原义。新档存档编号为 6–9，界面排在旧档之前；这些档位没有段位评级。

## 持驹消失的复现与修复

使用双方各一王、先手持两步的局面，将持驹拖到工具栏上松手。修改前测试发现 `pointer_id` 和 `drag_drop` 未清除，二维绘制继续隐藏原位置的持驹。相同测试在修复后通过，持驹数量始终为两枚。

棋盘拥有的触摸现在先处理松手与取消，再进行界面命中判断；转屏、取消触摸、前后台切换会清理拖动状态。同种持驹有多枚时，拖动一枚仍显示剩余的棋子和数量。另修复三维模式的拖动显示：持驹托盘使用二维绘制，拖动棋子也留在该可见图层，避免依赖被隐藏的三维持驹模型。二维／三维拖动中各剩一枚的截图均已检查。

复现原始记录保存在本地 `review/app/experience36/baseline-drag.json`。此路径证明了一个具体原因，不代表已复现用户设备上的所有偶发情况。

## 性能与棋力验证

实时分析等待 200 毫秒以合并连续翻阅请求，先进行 300 毫秒单候选搜索，再进行最多 1.7 秒的多候选搜索；“继续深入”最多增加 8 秒。引擎输出间隔为 100 毫秒，界面更新不超过每秒十次。缓存最多保留 160 个包含完整走棋历史及引擎配置的结果。

Windows 本地的一次开局、五候选测试中，旧流程首次引擎结果约 432 毫秒、全部完成约 1.72 秒；新流程首次结果约 117 毫秒、全部完成约 2.02 秒。两种流程均重新启动引擎以清空搜索缓存，数据不包含引擎加载时间、新流程的 200 毫秒防抖以及界面绘制时间。**首条结果提前，不代表所有局面的完整搜索时间都缩短**；再次查看缓存局面已验证不会重新搜索。原始数据见本地 `review/app/experience36/analysis-timing.json`，每次测试会更新。

四档新手电脑使用随机合法走子与轻量浅搜索，随机概率依次为 100%、60%、35%、15%。在固定的无保护飞车局面和 64 个随机种子下，吃车次数依次为 7、35、48、55。还进行了调换先后手的 40 手对局，检验合法走子与运行稳定性；这些短对局不能用于段位或胜率标定。原始记录为 `review/app/experience36/difficulty.json`。

## 验证方法与限制

本地所列套件共 **2,979 项检查通过**：核心逻辑 1,611 项，新增交互与真实引擎 81 项，原有界面回归 1,065 项，Windows 成品 161 项，APK 61 项。Windows ZIP 内的可执行文件与通过检查的文件哈希一致，且包含引擎、NNUE 和引擎源码。包大小、SHA-256 与实机验证状态见 [最终验证记录](releases/v0.36.0-test-validation.json)。

源码测试脚本不随安装包分发；成品新增功能由 `--package-probe` 的随包诊断验证，包含四档弱电脑、持驹拖动、自动五候选、完整棋路与分析展开／暂停。

```powershell
./scripts/test_experience36.ps1
./scripts/test_experience36.ps1 -CoreOnly
./scripts/test_package.ps1 -ReportDirectory review/app/experience36/package -Executable builds/windows-0.36.0-test/Shogi.exe
```

测试覆盖规则、存档难度兼容、升变提示、棋子身份、变化树、棋谱库、原有三语布局、保存与续下、回放导航，以及新的嵌套触摸滚动、长棋路、分析展开、自动启动、暂停、缓存、过期结果、引擎失败重试、报告互斥与坏棋重试。二维／三维、360×760 竖屏及 852×393 横屏的分析截图已经人工检查；三语与明暗主题由原有布局回归覆盖。

当前 ADB 未发现设备或模拟器，因此 **Android 实机触摸、前后台恢复、耗电和同机性能对照尚未验收**。APK 的构建、签名、内容及对齐检查不能替代手机实测。Windows 上采用实际绘制窗口和触摸事件测试；无界面测试另行覆盖逻辑。

Android 测试包使用 debug 导出和开发签名，不能宣称可直接覆盖任意已安装的 release 签名版本；本次没有执行安装、卸载或清除应用数据。
