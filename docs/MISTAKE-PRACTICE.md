# 报告中的失误练习（0.13–0.14）

详细报告或棋盘下方的报告面板 → 复习失误 → 开始练习。筛选双方／先手／后手，以及漏着、错失胜机、失误、不精确、锐利、妙手；默认只选漏着、错失胜机和失误、跳过已尝试着手。数量按已有分析结果及合法最佳着实时计算，没有题目时不可开始。

## 出题、判答与提示

每题从原着之前的局面开始，按答题方翻转。落子、持驹打入、可选／强制升变和落子确认均使用现有规则及输入流程。判答比较报告保存的首选 USI 着手，包括起点、终点、打入棋种和升变标志。其他着手只提示“这不是报告中的最佳着”，不声称它必然是坏棋。

本版不在答题时重新搜索等价解，因此题目质量取决于该次分析预算；浅层报告的首选可能随深入搜索改变。报告中的非法首选不出题。答案线路逐手验证，遇到非法后缀立即截断；线路首手与最佳着不符时只回放已验证的最佳着。

错误尝试先播放落子，再动画退回题目起点。提示分两级：先指出棋子或持驹，再显示落点和完整记谱。揭晓答案播放真实落子；答对或揭晓后可自动／逐手回放已保存的最佳线路，并返回原题。下一题、重试和退出线路会等待正在进行的动画结束，避免中途替换棋盘状态。

练习中隐藏评分、胜率、实时引擎和坏棋辅助，避免提前显示答案；练习不需要额外引擎搜索。当前只练习一份报告，没有跨多份棋谱的汇总题库。

## 原局与进度

`shogi_mistake_practice.gd` 持有独立练习棋局；主程序的 `app.game` 始终指向真实活动对局。练习通过 `review_game` 显示，暂停活动对局时钟和电脑应手。退出恢复先前棋谱对象、回放手数、路径、朝向和报告选中手。查看菜单等其他页面会先退出练习；升变和落子确认仍属于当前练习。

进度沿用学习记录的原子保存、读取保护和备份结构，以 `mistakes/<SHA-256>/0` 保存。散列由原局起点、该手之前的完整 USI 历史和当前最佳着组成；改棋手名称不丢进度，重新分析得到不同答案会生成新题标识，相同 SFEN 但不同历史不会混为一题。

仅未看提示、未揭晓且没有答错的完成计为独立答对。提示后完成、直接揭晓和跳过分别计数；错误次数与完成尝试持久化。重试不会在本轮按同一题重复加总。保存失败通过练习面板显示错误；不会将未保存状态描述为已成功持久化。
