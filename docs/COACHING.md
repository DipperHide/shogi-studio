# 对弈辅助

坏棋提醒使用独立 YaneuraOu 会话，每个局面搜索 500 毫秒，分析刚走这手之前与之后的局面，统一评分方向后比较损失。损失达到 300 且本手不是引擎首选时显示“可能是失误”。提醒带有实际引擎候选线路，可进入失误前局面复盘、播放线路或重新下。

搜索携带完整已有着手与初始 SFEN，支持持驹、升变和自定义起局。结果通过对局实例、手数和局面键校验；悔棋、新对局、替换棋局清除旧提醒。在联机模式不运行辅助分析。人机模式只点评人的着手，同机双人点评双方。

胜率栏只显示当前局面的引擎数据，不复用其他局面的旧数字。统一以先手、后手标识，翻转棋盘不改变归属。显示的是 `1 / (1 + exp(-score / 600))` 换算的**局面胜率估计**，不是根据本用户水平校准的胜率或获胜保证；将死评分显示对应端点。该换算方法可参见开发者的[评价值与胜率研究](https://tadaoyamaoka.hatenablog.com/entry/2017/05/24/220807)。短时搜索可能漏看战术，可使用深度报告继续分析。

“好棋线路”直接打开已有实时多候选分析；每行右侧播放按钮进入独立预览，并支持逐手动画。原对局保持可返回。对弈设置中可分别关闭坏棋提醒和胜率估计。
