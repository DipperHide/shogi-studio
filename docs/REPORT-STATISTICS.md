# 报告分类与质量图

0.23 继续适配用户提供的 Chessis 20.9 基础 APK 中的报告区域。原 APK 缺少运行所需分包，本节以布局及代码为依据，未进行原版运行画面的逐像素比较。

## 统计结构

`dialog_game_report.xml`、`C4570h.m9429w` 和 `ViewOnClickListenerC4568f` 指定：默认显示定式、妙手、锐利、失误、漏着；任一方存在错失胜机时显示该行。最佳、优秀、好棋、不精确和两张饼图由下方展开按钮一次性展开。分类帮助位于三列标题的中间，双方姓名为 13 sp 单行省略，计数列与下方饼图对齐。

实现使用原生按钮和网格。分类图标保持 22 像素；计数显示原始手数。展开状态在同一报告的详情往返中保留，换一份报告时重置。窄屏中心列保留 104 像素，左右列平分余宽；每张图高 200 像素，直径依据较小尺寸计算，不拉伸。

## 三组加权数据

原 `C1735i.m2703b` 与 `C4239p` 的分类计数对应关系为：

| 组 | 权重 | 色值 |
|---|---|---|
| 严重失误 | 漏着 + 错失胜机 | `#ff0000` |
| 不够精确 | round(不精确 / 2 + 失误) | `#ffff00` |
| 良好着手 | 定式 + 妙手 + 锐利 + 最佳 + 优秀 + 好棋 | `#00ff00` |

图中占比以这三个权重之和为分母，不能解读成原始手数占比。半次取整遵循 Java 非负 `Math.round` 行为，例如 1、2、3 次不精确分别计为 1、1、2。图内显示一位小数，说明卡显示一位小数及百分号。说明卡和无障碍描述明确标识加权含义；不改变现有将棋准确率、胜率和着手分类模型。

## 图形与操作

`C4570h.m9414E/m9418K`、`PieChart` 默认值与百分比格式器 `C0402b` 提供三色、3 像素间隔、选中外扩 5 像素、白色 50% 内孔、61% 半透明环、10 sp 黑色百分比、顶部起始角、旋转和 0.9 衰减配置。Godot 环形图使用这些参数；小切片间隔为避免图形消失做了上限保护，扇区采用多边形近似，不能视为完整移植 MPAndroidChart 渲染器。

展开提供 800 ms 三次缓入动画，点选显示 140 ms 淡入说明。原代码配置了 800 ms 动画，但优化后的 DEX 没有保留完整动画属性，所以这里只重建配置意图。说明卡未复现原版 4 像素位移动画。

触摸／鼠标点选环形区域，拖动旋转并在释放后衰减。内孔及图外不选择切片。左右键、Home/End 在非空组之间选择；焦点环和说明文本帮助键盘及辅助操作。

## 返回棋盘

`ViewOnClickListenerC4569g` 发出分类事件，`MainActivity.m4545h0` 将事件转交棋盘分类控制并关闭报告。本项目相应将整行及任一侧计数作为双方该类着手的入口，回到原始手数位置；棋盘分类按钮按当前双方／先手／后手筛选向后定位，末尾回到首处。该循环顺序是明确的将棋适配选择，未声称核验原版所有筛选配置的顺序。

定位使用已有动画回放流程，保留原局对象、棋谱及计时余额。质量图点选仅显示说明，不返回棋盘。
