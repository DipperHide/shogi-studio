评价条新增 51 项核心断言及 289 项界面断言，覆盖四种尺寸、两种外观、四种位置策略、实际引擎报告、原生下拉窗口键盘选择、连续与中断动画、未知局面清空、詰手数、终局边界和左侧按钮续下。见 [评价条说明](EVALUATION-BAR.md)。

变化回归覆盖同一棋谱的嵌套分支、主线提升／替换、删除撤销、独立注释和绘图、转置路径、千日手、非法数据及文件大小限制。界面测试通过实际触摸和长按，检查横竖屏、两种外观、完整 JSON 导出、备份恢复、保存失败后重试、实际引擎分支报告、候选返回和从分支继续下棋。详细边界见 [变化分析](VARIATIONS.md)。

原有回放的 36 次中途切换保持 40 枚棋子的姿态连续。22 段计时中仍有 **14 段超过 50 毫秒目标**，最大 **510.867 毫秒**；本轮动画探针在构建和核心回归前执行；这些是 Windows 测试环境的观测值，不能据此推断 Android 表现。上一版空窗口也出现绘制停顿，原因仍未解决，见 [动画衔接说明](ANIMATION-CONTINUITY.md)。

Windows 成品通过 101 项检查，首次棋盘绘制 1953 毫秒。APK 使用 release 模板、versionCode 44、原包名与开发签名，ARM64／16 KiB 对齐；没有会员模块或测试夹具。发布文件哈希、源文件清单与受测 Windows 程序已校验。

首次成品检查与历史棋谱回归同时执行，一项「缓存报告回放显示中间帧」检查失败。停止其他构建／回归任务后，同一个 Windows 文件再次完成检查；首轮失败保存在 `initial_package_probe_failures` 中，不据后续通过宣称卡顿已解决。
