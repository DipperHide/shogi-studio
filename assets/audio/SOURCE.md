# 落子音来源

`selected-snap-source.wav` 来自用户提供的 `C:/Users/jinda/Documents/录音/录音 (2).m4a`。

先将录音转换为 44.1 kHz 单声道 PCM，再截取约 4.725–4.930 秒，移除直流偏移、在两端添加短渐变、归一化峰值到 0.7，得到用户选定的 `sample-02.wav`。用户反馈：“sample-02.wav 类似”。本文件保留该选定片段，供可复现处理。

0.4.4 按用户“刺耳、不够清脆、声音小一点”的反馈处理。运行 `scripts/build_wood_sound.py`，对 8.2 kHz 附近作 -5 dB 宽带削减（Q 0.85），整体增益 -2.5 dB；保留起音，32–95 ms 平滑收尾。没有加入合成音、变调或重新归一化。与旧 120 ms 版本按相同时长比较，整体电平下降约 4.99 dB，峰值约 -8.97 dBFS。

Godot 导入改为无压缩 16-bit PCM，避免有损编码对短促瞬态的影响。参数、频谱、零削波检查在 `review/app/v044/audio-checks.json`，试听文件为同目录 `wood-place.wav`。目前只有波形/频谱与运行时导入验证，没有直接听辨验收。

此录音不标注为项目原创合成音。原始用户录音及选定源片段未修改。
