# Reference UI provenance

The user supplied Chessis 20.9 (`com.chessimprovement.chessis`) and requested a shogi adaptation of its interface. This folder contains 22 converted vector interface icons and its dark wooden background, taken from that supplied APK for this local adaptation. The vectors retain the original path geometry and are tinted by the shogi interface. No original executable, chess piece collection, player photo, bot illustration or service credential is packaged here.

`provenance.json` records the supplied APK SHA-256 and decoded-source hashes. This provenance record does not assert a new license for the original artwork.
